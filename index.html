안진 검출 Type 비교

그래프는 위에서부터 지금 방식, Type 1, Type 2입니다. 그래프 선은 같고 안진 표시(검은 선)만 다릅니다. 노란 배경은 지금 방식과 안진이 다른 곳입니다. 영상을 틀면 빨간 선이 같은 시각을 따라가고, 그래프를 누르면 영상이 그 시각으로 갑니다.

안진을 잡는 방법

0.0초
단축키: 스페이스 재생·멈춤, ← → 1초 이동, ↑ ↓ 이전·다음 구간

안진을 잡는 방법

지금 방식, Type 1, Type 2 모두 화면에 그려진 그래프 선(꺾은선)에서 안진을 찾습니다. 그래프 선 자체는 셋이 같고, 어떤 톱니를 안진으로 표시할지만 다릅니다. 페이지의 그래프는 왼눈 가로(H)입니다. 안진 하나는 느린 상의 시작점에서 끝점까지 그은 선으로 표시합니다.

공통: 톱니 하나를 찾는 방법

  1. 그래프 선에서 빠르게 되돌아가는 조각(급속상)을 찾습니다.
  2. 그 바로 앞에서 반대 방향으로 천천히 흐르는 구간(느린 상)을 찾습니다.
  3. 느린 상의 크기, 길이, 속도가 기준 안에 들면 톱니 후보 하나가 됩니다. 느린 상 속도(SPV) = 느린 상 크기 ÷ 느린 상 시간.
  4. 두 눈 조건과 반복 조건을 통과한 후보만 안진으로 표시합니다.

Positional Nystagmus: 지금 앱의 기준 (검정 선)

  1. 급속상: 40°/s 이상인 조각, 또는 8°/s 이상이면서 바로 앞 조각보다 1.5배 넘게 가파른 조각. 계단처럼 나뉜 급속상(오름, 짧은 평평, 오름)은 하나로 묶습니다. 묶은 급속상은 0.3° 이상, 0.5초 이하.
  2. 느린 상: 0.1~2초, 0.5° 이상, 속도 1~60°/s. 느린 상 안의 작은 되돌림(1° 미만, 0.3초 이하)은 무시합니다.
  3. 두 눈: 다른 눈에도 같은 방향 안진이 0.3초 안에 있어야 합니다. 다른 눈에서 톱니로 안 잡혔더라도 같은 시간에 같은 방향으로 0.5° 이상 흐르고 0.25초 안에 되돌아오면 인정합니다.
  4. 반복: 앞뒤 4초 안에 같은 방향 안진이 2개 이상(자기 포함)이고 반대 방향의 2배 이상.
  5. 약한 톱니: 급속상이 느려 위에서 못 잡은 것 중, 0.5° 이상 흐른 뒤 0.25초 안에(느린 상 시간의 절반 이하) 0.5° 이상 되돌아오는 것. 다른 눈에도 있고 앞뒤 4초 안에 같은 방향 뚜렷한 안진이 2개 이상, 반대 방향은 없을 때만 더합니다.

Post Head Shaking Nystagmus: 지금 앱의 기준 (검정 선)

  1. 급속상: 15°/s 이상인 조각(같은 방향으로 이어진 조각은 하나로 묶음). 묶은 급속상은 0.5° 이상이고, 40°/s 이상이거나 느린 상보다 2.5배 넘게 빠름.
  2. 느린 상: 0.1초 이상, 0.5° 이상, 속도 1~60°/s.
  3. 머리를 흔드는 구간과 그 뒤 0.5초, 눈을 놓쳐 1초 넘게 직선으로 이은 곳에 걸친 것은 뺍니다.
  4. 두 눈: 다른 눈에도 같은 방향 안진이 0.3초 안에 끝나야 합니다.
  5. 반복: 앞뒤 4초 안에 같은 방향 안진이 2개 이상(자기 포함)이고 반대 방향의 2배 이상.

Type 1: 진짜 안진을 지우지 않는 쪽

  1. 지금 안진에서 잘못 묶인 것만 뺍니다: 느린 상 구간 안에 빠른 움직임(40°/s 이상, 0.5° 이상)이나 왔다 갔다 하는 움직임이 끼어 있어 표시선이 그래프에서 떨어진 것(0.5° 이상이면서 느린 상 크기의 25% 이상).
  2. 남은 것 중 역방향을 뺍니다: 앞뒤 5초 안에 반대 방향 안진이 같은 방향(자기 포함)의 2배 이상인 것.
  3. 드문드문 나오는 안진은 지우지 않습니다. 잠깐씩만 나오는 진짜 안진과 구분할 수 없기 때문입니다.
  4. 지금 앱이 조건에서 떨어뜨린 톱니(한쪽 눈에만 보임, 반복 없음, 약한 톱니, 느린 급속상) 중, 안진이 모여 있는 곳 주변의 것만 더합니다: 앞뒤 5초 안에 모여 있는 안진(앞뒤 8초 안에 같은 방향 6개 이상)이 같은 방향으로 2개 이상 있고 반대 방향의 2배 이상, 눈 깜빡임에 걸치지 않음, 표시선이 그래프에 붙어 있음, 이미 있는 안진과 겹치지 않음.

Type 2: 놓친 톱니를 넓게 더하고 드문드문한 것을 지우는 쪽

  1. 지금 앱이 조건에서 떨어뜨린 톱니(한쪽 눈에만 보임, 반복 없음, 약한 톱니, 느린 급속상)를 먼저 모두 더합니다.
  2. 그다음 드문드문한 것을 뺍니다: 앞뒤 8초 안에 같은 방향 안진이 6개 미만이거나 반대 방향의 2배가 안 되는 것. 단, 모여 있는 안진에서 10초 안에 있고 같은 방향이 3개 이상이면 남깁니다.
  3. 눈 깜빡임에 걸친 것을 뺍니다.

Type 1과 Type 2의 차이

Type 1Type 2
지금 안진에서 빼는 것잘못 묶인 것, 역방향드문드문한 것, 눈 깜빡임에 걸친 것
드문드문한 안진지우지 않음지움
더하는 것안진이 모여 있는 곳 주변의 톱니만떨어뜨린 톱니를 모두 넣은 뒤 삭제 기준 통과한 것
잠깐씩 나오는 안진남음일부 지워짐
안진 없는 환자지금 방식과 거의 같게 남음환자에 따라 다름. 0개가 되는 환자도 있고(S11, S13, S18), 더해진 톱니가 모여 있으면 남는 환자도 있음(S07, S08, S09)

표시: 검은 선 = 그 방식이 최종으로 잡는 안진. 노란 배경 = 지금 방식과 안진이 다른 곳(더해졌거나 빠진 곳). OKN은 지금 방식과 Type 1만 있습니다.

mean SPV · peak SPV: 그 방식이 표시한 안진들의 느린 상 속도(°/s)의 평균과 최댓값입니다. 방향과 관계없이 크기(절댓값)로 계산했습니다. 그래프 제목의 값은 그 구간, 위쪽 요약 줄의 값은 기록 전체입니다.
